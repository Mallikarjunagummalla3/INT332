# Docker Basics: File Operations

This repository contains essential Docker commands and file operations used to manage containers, images, and volumes.

## Table of Contents
1. [Docker Commands](#docker-commands)
2. [File Operations in Docker](#file-operations-in-docker)
3. [Pro Tips](#pro-tips)

---

## Docker Commands

### 1. **Docker Version**
Check the version of Docker installed on your system.

### 2. **List Running Containers**
View all containers that are currently running.

### 3. **Start a Stopped Container**
Start a container that is stopped.

### 4. **Stop a Running Container**
Stop a currently running container.

### 5. **Run a New Container**
Create and start a new container from a specified image.

### 6. **View Container Logs**
Access the logs of a running or stopped container.

### 7. **Remove a Container**
Delete a container from your system.

### 8. **List Docker Images**
View all Docker images available locally.

---

## File Operations in Docker

### 1. **Copy Files from Host to Container**
Copy a file or directory from your local machine to a container.

### 2. **Copy Files from Container to Host**
Copy a file or directory from a container to your local machine.

### 3. **View Files Inside a Container**
Access the container's file system and view its contents.

### 4. **Move Files Inside a Container**
Move or rename files within the container.

### 5. **Remove a File from Container**
Delete files inside the container.

### 6. **Create a File in the Container**
Create a new file within a running container.

### 7. **Mount Host Directory to Container**
Mount a local directory to the container for file synchronization.

---

## Pro Tips

- **Volumes**: Use volumes to store persistent data.
- **File Syncing**: Mount directories to keep files in sync between the host and the container.
- **Backup**: Regularly back up important files from containers to your host.
